#  Adinath  Ugale — 3D AI & Data Science Portfolio

Welcome to my personal portfolio website.

I’m **Adinath Ugale**, an AI & Data Science Engineering student and an aspiring Data Scientist. I built this portfolio to showcase my skills, projects, certifications, experience, and the things I’m continuously learning in the field of AI, Data Science, and modern web technologies.

Instead of creating a traditional portfolio, I wanted to build something more interactive and visually different — so I designed it around a **futuristic 3D AI / Neural Network theme**.

---

##  About This Portfolio

This website represents my journey as an AI & Data Science student.

The main goal was to create a portfolio that is:

- Modern and visually attractive
- Interactive and responsive
- Easy for recruiters to explore
- Focused on my real skills and projects
- Fast and simple to deploy
- Easy to update in the future

I have tried to keep the information genuine and based on my actual academic journey, projects, certifications, and experiences.

#  What I Built

##  1. Interactive 3D Neural Network Hero Section

The landing section contains an interactive **Three.js 3D neural network scene**.

I implemented:

- 3D neural network nodes
- Dynamic connections between nodes
- Floating particles
- Data-stream style visual effects
- Mouse-based parallax interaction
- Camera movement
- Glowing AI-inspired visual effects
- Responsive behavior for different screen sizes

The idea was to visually represent how data flows through an AI system.

##  2. KisanMitra AI — Flagship Project

One of the main projects highlighted in my portfolio is **KisanMitra AI**.

It focuses on using AI and technology to help farmers make better decisions.

The portfolio includes an interactive 3D visualization for the project with elements such as:

- Digital crop structures
- AI-inspired agricultural environment
- Sensor / telemetry nodes
- Crop monitoring visualization

- Interactive 3D elements
- Project overview

This project is one of the major practical applications I have worked on while learning AI and Data Science.

# 10. Centralized Portfolio Configuration

One thing I specifically worked on was making the portfolio easy to maintain.

Instead of keeping all information scattered throughout the HTML, the portfolio uses:

`js/profileConfig.js`

This file can contain information such as:

- Personal details
- Social links
- Skills
- Certifications
- Projects
- Resume information
- Contact configuration

This makes future updates much easier.

For example, when I want to add a new certification or project, I can update the configuration instead of searching through the entire HTML file.
